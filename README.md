# git-lex-kit-pan

The Pan media store's kit for git-lex. Installing it into a soul repo
(`git lex kit-add repolex-ai/git-lex-kit-pan`) installs the pan ontology to
`.lex/ontology/pan/` so git-lex knows the `pan:` vocabulary and can read the
soul's media graph at `.pan/_ignore/oxigraph` — the store `pand` writes.

Ontology source of truth: `repolex-ai/pan` (`ontology/pan.ttl`). This repo is
a published copy; do not edit it here.
